Gestura

Gestura is a browser-based accessibility and two-way American Sign Language (ASL) communication platform designed to bridge the gap between signers, deaf/hard-of-hearing users, and vocal speakers.

Core Capabilities

Live Caption & Transcript Sync: Reads in-page YouTube captions and displays a clean, synchronized transcript inside a convenient Chrome side panel.

Real-Time ASL Sign-to-Text: Uses webcam capture and MediaPipe hand landmark tracking to translate ASL hand gestures into live text and synthesized speech.

Accessible Controls: Built with intuitive controls for pausing, resuming, clearing, undoing, and speaking translated text aloud directly in the browser.
